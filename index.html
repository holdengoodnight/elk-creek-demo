HOW IT WORKS

A straightforward path from idea to finished work.

Every project is different, but the process should still feel simple. Start with the basics, define the scope, and move forward with clear communication.

01
FIRST CONTACT

Tell us what you need

Call, message the Facebook page, or use the project form to share the type of work, location, and what you are hoping to accomplish.

02
PROJECT REVIEW

Review the scope

Details like condition, size, timing, materials, access, and the desired result help define what the project actually needs.

03
PLAN & SCHEDULE

Set the next steps

Once the scope is clear, the work can be planned around materials, scheduling, access, and the specific needs of the property.

04
BUILD / RESTORE

Get the work done

The project moves forward with hands-on craftsmanship and direct communication from start through completion.
