# Elk Creek Wood Products Website Prototype — v3

This version was redesigned after reviewing multiple professional log-home restoration,
custom-home, and wood-restoration websites from around the United States.

Design patterns intentionally adopted:
- Prominent phone number and quote CTA above the fold
- Large value-proposition hero
- Clear service cards
- Simple project process
- Documented project/experience section
- Strong repeated calls to action
- FAQ
- Structured project inquiry form
- Mobile sticky call button

No paid services are required to preview or host this prototype.
